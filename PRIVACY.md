# Privacy and data handling

Sarim's School Tracker stores attendance, study time, extra-work progress, XP, streaks, and achievements in the browser for the person using the device.

## Current data boundary

- The app does not require an account.
- Progress remains in browser storage and is not sent to an application server.
- Clearing the site's browser data removes locally stored progress.
- Anyone who can use the same browser profile may be able to view that progress.

## Safe use

Use a personal browser profile on shared devices and avoid entering sensitive notes or identifying information. This project is a study companion, not an official school attendance record.

## Future changes

Any future analytics, synchronization, accounts, or cloud backup must be opt-in, documented here, and designed to collect the minimum data needed. Secrets and student records must never be committed to the repository.
